# Agent Skills

A collection of reusable skills that follow the [Agent Skills specification](https://agentskills.io/specification).

## Collections

| Collection | Purpose |
| --- | --- |
| [`writing`](skills/writing/) | Research, draft, review, and share Japanese technical blog articles in azukiazusa's house style. |

## Install

List the skills available in this repository:

```bash
npx skills add azukiazusa1/skills --list
```

Start the interactive installer and select the skills and target agents:

```bash
npx skills add azukiazusa1/skills
```
